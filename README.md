# 📊 Проект: Анализ вакансий с hh.ru и сохранение в PostgreSQL

## 📌 Описание

Этот проект автоматически получает данные о компаниях и вакансиях с сайта [hh.ru](https://hh.ru) через публичный API, сохраняет их в базу данных PostgreSQL, а также предоставляет консольный интерфейс для анализа данных.

---

## ⚙️ Используемые технологии

- Python 3.10+  
- PostgreSQL 14  
- psycopg2  
- requests  
- dotenv  
- PEP 8 / SOLID / модульная структура

---

---

## 🧠 Что умеет проект

### 🗃️ Работа с базой данных
- Автоматическое создание базы данных `hh_vacancies`
- Создание таблиц `companies` и `vacancies`, связанных через внешний ключ
- Удаление и перезаполнение данных для повторных запусков

### 📡 Получение данных
- Загрузка информации о 10+ компаниях и их вакансиях с hh.ru
- Обработка JSON с учетом пропущенных полей (например, зарплаты)

### 📦 Хранение данных
- Таблица `companies`: название компании, `hh_id`
- Таблица `vacancies`: название, зарплата, ссылка, внешний ключ на компанию

### 🛠️ Класс `DBManager`

Предоставляет интерфейс для работы с данными в БД:

| Метод | Назначение |
|-------|------------|
| `get_companies_and_vacancies_count()` | Компании и число вакансий |
| `get_all_vacancies()` | Все вакансии с деталями |
| `get_avg_salary()` | Средняя зарплата |
| `get_vacancies_with_higher_salary()` | Вакансии с з/п выше средней |
| `get_vacancies_with_keyword(keyword)` | Поиск вакансий по ключевому слову |

### 🖥️ Пользовательский интерфейс

Интуитивно понятное текстовое меню, через которое можно:
- посмотреть статистику
- отфильтровать вакансии
- выполнить поиск по ключевым словам

## 📦 Установка

1. Клонируй репозиторий:

    ```bash
    git clone https://github.com/Babka_Shura/project3.git
    cd project3
   ```
2. Создайте виртуальное окружение и активируйте его:

    ```bash
    python3 -m venv .venv
    source .venv/bin/activate  # Linux/macOS
    .venv\Scripts\activate     # Windows
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Создайте файл .env:

   ```bash
   DB_USER=postgres
   DB_PASSWORD=postgres
   DB_HOST=localhost
   ```

5. Убедитесь, что PostgreSQL установлен и запущен (порт 5432).


## 🚀 Запуск 

```bash
    python main.py
```
